# Codex Aetheon

> Este no es un lugar que poseer, sino que cuidar y proteger.

---

## ¿Qué es Aetheon?

Aetheon es una cosmogonía construida alrededor de un lugar real.

No pretende únicamente documentar un espacio físico, sino preservar las relaciones, acontecimientos, símbolos y memorias que le dan identidad.

---

## ¿Qué es el Codex?

El Codex constituye el soporte documental de Aetheon.

Su función no consiste únicamente en almacenar información, sino en permitir que Aetheon conserve continuidad a través del tiempo.

---

## Estructura

El proyecto se organiza en torno a tres pilares:

- El Canon (realidad documentada).
- Las Resonancias (literatura y simbolismo).
- La Gobernanza (principios editoriales del Codex).
