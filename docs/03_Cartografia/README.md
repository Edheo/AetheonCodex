# Cartografía

Este directorio contiene la representación espacial canónica del Atlas.

Los ficheros aquí almacenados constituyen la referencia oficial para la
ubicación de Guardianes, Arquitecturas y demás elementos de Aetheon.

Toda representación gráfica o interactiva deberá derivarse de estos
ficheros, evitando duplicar información cartográfica en otros documentos.
